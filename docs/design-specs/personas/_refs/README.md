# 参考图来源（第二批形象）

每个子目录放当组生成时喂给 gpt-image-2.5 的参考原图 + `source.md`（URL、作者、授权原文）。两个来源：

1. **aigengtu.com「AI 娘设定图库」** `https://aigengtu.com/refs?lang=zh-Hant`（2026-11-01 抓取；页面是前端渲染，索引在 `https://aigengtu.com/public/refs.json`，原图在 `https://img.aigengtu.com/refs/<文件名>`）。页面「图片来源与版权」原文：
   > 标「本站自有」的条目（DeepSeek 娘 7 套三视图）由本站制作，可自由下载用于个人二创。
   > 其余条目转载自 ZipZipPipe 的 B 站专栏，遵循 CC BY-NC-SA 4.0；DeepSeek 娘原角色由 上善无形 设计。每张图均标注作者、协议与原帖链接，版权归原作者所有，本站不作商业使用。
   > 如原作者不希望作品在此展示，请通过 站内投稿入口 或邮箱告知，我们会在 24 小时内下架。

   `refs.json` 里的说明：`owned=true 才可下载/复制/打包；转载条目必须保留 author/license/sourceUrl（CC BY-NC-SA 4.0 署名要求）`。`gj-` 前缀 = 转载。
2. **萌娘百科「DeepSeek娘」** `https://mzh.moegirl.org.cn/DeepSeek娘`。站点有 Cloudflare 盾，curl / API 都拿不到，用的是 Wayback 2026-02-06 快照（`web.archive.org/web/20260206213317/`）。正文 CC BY-NC-SA 3.0，图片各有作者。

「本站自有、可自由下载用于个人二创」和 CC BY-NC-SA 都是非商用口径，和现在 app 的内测用途一致；上架商用前要换图。
