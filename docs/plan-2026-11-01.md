## 架构

```
iPhone app ──WSS(E2E 加密)──► 中继 rex-voice-relay（ccs-maruiao，nginx 后）◄──WSS(E2E 加密)── Mac 服务 rex-voiced
                                                                                         │ WebSocket  │ exec rex / 读 ~/.claude/projects
                                                                                      OpenAI Realtime   Rex、Claude 转录
```

- **音频走 Mac**：手机只收发 PCM 帧，OpenAI 的 WebSocket 由 Mac 持有。理由：key 不出 Mac；手机在国内也不用自己够到 OpenAI；工具执行、上下文裁剪、将来换模型都只改 Mac 一处。Mac→OpenAI 23 ms，手机→中继→Mac 在美国约 40 ms、在国内约 300–400 ms（和现在用 Rex 同级）。
- **中继只转发**：按配对 id 把两条 WebSocket 对接，内容 ChaCha20-Poly1305 端到端加密（密钥来自二维码），中继看不到明文。放 `r.maruiao.top/_voice/`（复用现成证书和 nginx，不用改 DNS）；想换独立子域名要用户在阿里云 DNS 加记录，见「要用户定」。
- **配对**：Mac 上 `rex-voiced pair` 在终端打二维码（内容 `rexvoice://pair?relay=wss://r.maruiao.top/_voice/ws&id=<16B>&key=<32B base64url>`），app 扫码后存 Keychain，之后开 app 即连。二维码一次性：Mac 收到首个握手后作废。
- **语言**：Mac 服务与中继用 **Go**（全局规则：新独立服务 Rust/Go 二选一，不需共享 TS 代码、无高危 bug 代价 → Go），单二进制、launchd / systemd 常驻；app 用 **SwiftUI + 系统框架**（AVAudioEngine、CryptoKit、AVFoundation 扫码），不引第三方库，不用 WebRTC。

## 功能范围（第一批一次做完、一起上）

1. **通话**：开 app 自动连 Mac，大按钮开始 / 挂断；锁屏、后台保持（`UIBackgroundModes: audio`，AVAudioSession `.playAndRecord` + `.voiceChat`），耳机 / 蓝牙可用。
2. **语音挂断**：工具 `hang_up`，提示词里规定听到「挂断吧 / 先这样 / 拜拜」类意图就先说一句再调它；Mac 关 OpenAI 会话、通知 app 结束。另外**静音 90 秒自动挂断**（先提醒一次），OpenAI 对静音也按音频 token 计费（约 $0.7/小时），这是最大的浪费点。
3. **读 Rex 与 Claude**（从 voice-probe 移植，已验证）：list_panes（带项目名）、read_pane、list_claude、read_claude（读转录 JSONL，不受屏幕滚动影响）、send_to_pane（先复述再发；含生产 / 部署 / 上线 / 发布 / 回滚 / 迁移 / rm -rf / git push / sudo 的拒发）。
4. **更准**：
   - `read_claude` 精确对应窗格：Claude 进程 → `lsof` 找它打开的转录文件；找不到再退回按目录取最近两份（实验版做法）。
   - 工具返回结构化摘要而不是整屏文字：Claude 的「最后一条用户指令 / 最后一段回复 / 是否在等人（blocked）」；屏幕只在问「屏幕上现在是什么」时给。
   - 提示词带项目名表、会话标签表（启动时从 `rex ls` 生成），减少「geo-us」听成「GOS」。
5. **更省**：
   - **上下文裁剪**：每轮答完，Mac 用 `conversation.item.delete` 删掉已用过的工具输出（Realtime 每轮按全部上下文计费，实验里一次通话输入 token 从 700 涨到 2700）。
   - **静音不送**：app 端能量门限，低于阈值不发音频帧（服务端仍开 semantic_vad 断句）。
   - **模型可配**：默认 `gpt-realtime-2.1`；第一批验收时用同一组 20 句真实指令 A/B `gpt-realtime-2.1-mini`（音频 $10/$20 vs $32/$64，约 1/3 价，128K 上下文）和 `gpt-live-1`（$0.05/分钟计时，支持函数调用，走 `/v1/live/sessions` 另一套事件），比准确率、首音延迟、每小时花费，再定默认值并报给用户（全局规则：模型选型要拿真实任务比过）。
6. **安全**：E2E 加密 + 配对一次性；app 侧 Keychain 存密钥；Mac 侧密钥文件 0600；`hang_up`/`send_to_pane` 都写审计日志 `~/Library/Logs/rex-voice/`；prod-guard 加一条「来自 rex-voice 的输入不算授权」（改全局 `~/.claude/hooks/prod-guard.py`，改前把原文和 diff 给用户看）。
7. **TestFlight**：`scripts/build-ios.sh` 用 `xcodebuild archive` + `-exportArchive`（method app-store-connect、`-allowProvisioningUpdates`、ASC API key）直接上传；每次上传写 build 号和 commit 到 `docs/releases.md`。首个 TestFlight 要用户在 App Store Connect 建 app 记录并加自己为内测员（见「要用户定」）。

**不做（本批）**：整台 Mac 控制（工具注册表留接口，后续加 AppleScript / computer-use 组）、Claude 卡住时主动来电（要推送 / CallKit 来电，下一批）、多台 Mac、多用户。

## 协议要点

- 手机 ⇄ Mac 帧：`[1B type][4B seq][ciphertext]`，type：0 音频 PCM16 24kHz mono 20 ms、1 JSON 控制（`call.start`、`call.end`、`transcript`、`status`、`hang_up`）；nonce = 方向 + seq，密钥 HKDF(配对密钥, 方向)。
- Mac ⇄ OpenAI：`session.update` 里 `audio.input.format {type:"audio/pcm", rate:24000}`（只支持 24k）、`turn_detection semantic_vad interrupt_response`、`noise_reduction near_field`、`tools`；收到 `input_audio_buffer.speech_started` 即让 app 停播并发 `conversation.item.truncate`（WebSocket 模式要客户端自己截断）；会话上限 60 分钟，到 55 分钟无缝换会话（带上最近几轮文字摘要）。
- 工具调用：一轮里攒齐全部 function_call，并行执行，全部 `function_call_output` 送完再发一次 `response.create`（实验里踩过重复 create 的坑）。

## 验收

- 扫码一次后，开 app 即连，不依赖 Surge 规则、Tailscale ACL（手机蜂窝网下测）。
- 「geo-us 的 Claude 最后说了什么」直接说对（对照转录）；「屏幕上现在显示什么」读屏；「给它发：继续」先复述再发；「部署 geo 生产」被拒。
- 说「挂断吧」3 秒内通话结束；静音 90 秒自动挂断且先提醒。
- 锁屏、放口袋、蓝牙耳机各 10 分钟不断线；它说话时插嘴能打断。
- 20 句中英混合真实指令，准确率 ≥ 90%，三种模型各一轮，报表进 `docs/releases.md`。
- 花费：同一段 10 分钟脚本对话，裁剪前后 token 对比；静音 10 分钟花费接近 0。
- 中继上抓包看不到明文；二维码用过第二次被拒。
- Go：`go test ./...` 覆盖帧加解密、配对一次性、工具拒发规则、function_call 攒批；Swift：加解密与 Go 互通的向量测试。
- TestFlight 构建全程 CLI 完成，记录 build 号。

## 风险点

- iOS 后台录音：`audio` 后台模式下 AVAudioEngine 录音在锁屏后可持续，但系统电话 / Siri 会抢占音频会话，要处理中断恢复（待 coder 核实 iOS 26 行为）。
- SSH 下构建签名：登录钥匙串当前 no-timeout 且 `find-identity` 能看到证书，但重启或锁屏后会锁；见上一节的默认做法。
- Claude Terminal 的代码有许可限制，扫码、Keychain、推送这些都要重写（都是系统 API 的薄封装，各几十行）。
- 60 分钟会话上限与换会话时的上下文延续。
- Realtime 对静音也计费；能量门限太严会吞掉轻声说话，阈值要在真机上调。
- `gpt-live-1` 是另一套事件（`session.start` / `session.input_audio.append`），A/B 时要单独适配，工作量约半天；若不想花这个时间就只比 2.1 和 2.1-mini。
- `conversation.item.delete` 在 GA API 里的确切名字待 coder 核实（文档只明确了 truncate）。
- r.maruiao.top 上有 limit_req，WebSocket 位置要单独放行长连接。
